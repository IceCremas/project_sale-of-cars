# Car Sales Landing

Учебный лендинг для продажи автомобилей. Свёрстан по видео-курсу, разобрал структуру и доработал.

## Стек
HTML5, CSS3, JavaScript

## Что сделал
- Адаптивная вёрстка: шапка, каталог, форма заявки, футер.
- Фильтрация каталога по марке: активная категория подсвечивается, показываются только подходящие карточки, затем скролл к каталогу.
- Валидация формы: проверка на пустые поля и длины телефона, подсветка ошибок, сообщение об успехе и очистка полей.
- Структура проекта: `images/`, `styles/`, `scripts/`.

## Запуск
Открыть `index.html` в браузере.
